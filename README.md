### About Me

Cloud engineering is the direction I’m building toward, with **Microsoft Azure** as my main focus. I’m drawn to the infrastructure behind an application: how systems connect, how access is controlled, and how to find the cause when something stops working.

My programming background helps me understand the applications that infrastructure supports. Through my work at **RestSim**, I’ve gained experience with Linux VPS administration, databases, troubleshooting and the RQOS CI/CD pipeline, alongside developing and releasing web and mobile applications.

I’m currently studying **Cloud Computing Technologies at George Brown Polytechnic**, building on my Computer Programming background. My focus is on Azure administration, networking, identity, cloud security and automation.
